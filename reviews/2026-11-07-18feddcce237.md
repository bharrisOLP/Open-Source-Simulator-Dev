## Findings
No blocker. No major finding.

1. minor: fdtd_gpu/README.md:102-103 (and the error text at fdtd_gpu/src/fdtd_gpu/simulation.py:155-156). The
   reason "(fdtdx would make the whole axis periodic)" is correct but incomplete. The MIT package also makes the
   face without a PML Bloch-periodic when k_point is set, so it also wraps the fields across that axis. The real
   conflict in this package is that the fields wrap while `_periodic_axes` does not repeat the objects on an axis
   with a PML. A reader can think that the MIT package treats the case differently. Fix (optional): write "the
   fields would wrap across the axis, but the objects do not repeat along an axis with a PML".
2. minor: fdtd_gpu/src/fdtd_gpu/geometry.py:277. The comment "each copy that holds a cell center" is not exact. A
   part is kept for each copy whose bounding box holds a cell center; `contains` can be False for all of them (the
   `mask.any()` test handles that). Fix (optional): "each copy whose bounding box holds a cell center".
