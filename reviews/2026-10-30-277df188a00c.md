### Recommendation

- Hook: check every word strictly, also redirect targets and git arguments. Reject `<` and `>` in a word
  (allow only a separate `>` with a plain target, and `/dev/null`). Compare paths case-insensitively (`casefold()`
  of both sides) and reject a target that contains a PROTECTED path (`q.is_relative_to(target)`). Remove `printf`
  (or reject `-v`). Remove `cp -s`, `-l`, `-L`, `-H`, and do not approve a command that makes files and then uses
  them (one simple command per call is simplest). Reject `-files0-from`, `-f`. For git, allow exact argument
  shapes only: no `init`, no `clean` and no `rm`/`mv`/`restore`/`checkout` of PROTECTED paths, reject each
  `--no-v*` prefix of `--no-verify`, no `stash` ref outside `git stash`, no `--orphan`, no `-B`, no push of tags
  or of `stash`.
- Gate: in `.githooks/pre-commit`, fail when the gate text is empty, and fail on an unborn branch unless the
  staged gate equals a pinned hash. Hash the records too (or review them as a separate step) and use `--text`.
  Add a server-side check (GitHub Actions) for the gate.
