numbers are correct. Minor findings:

1. minor: suite/README.md:48-58 and :80, and suite/src/photonsuite/geometry.py:25. `phase_transient` is the first function
   of the suite that uses `Material.rho_cp`. The README snippet uses the `xs` of the top example, whose materials
   set no `rho_cp`, so the silent default 1.6e6 J/m^3/K applies to Si, SiO2 and the heater metal. The snippet then
   does not give the numbers of the results table (the table uses the Incropera values; the text says so, but only
   below the snippet). Fix: set `rho_cp` in the snippet (or in the top example), or say in the snippet comment that
   the default 1.6e6 applies; optionally warn when a material of the thermal window keeps the default.
2. minor: suite/README.md:86-96 (the 10-90 % times with 5 to 6 digits). The times depend on the time steps more than
   the digits show. The reviewer ran the constant-kappa switch-on with 10, 20, 40 and 80 steps per stage (dt0 20,
   10, 5, 2.5 ns): phase 10-90 % time 17.9051, 17.9385, 17.9449 and 17.9474 us. So the default steps give a time
   about 5e-4 to 6e-4 below the converged value. The "Limits" list gives the thermal-gpu values for 10/20/40 steps,
   so the dependence is disclosed. Fix (optional): add the 80-step value, or give the times as about 17.94 us
   (+0.05 % with finer steps). The ratios (kappa(T) 1.86 % and 0.38 % faster, 0.958 and 0.967 of the estimates) use
   the same steps and do not change.
3. minor: suite/src/photonsuite/switching.py:172-173 and :160-165 (untested paths). No test calls
   `rho_cp_laws` or `core_tag=None`. The reviewer ran both: `rho_cp_laws={"Si": Constant(SI.rho_cp)}` (the Picard
   path with constant laws) gives the constant-kappa switch-on to 1.1e-9 in the switch time and 5.4e-13 of the step
   in dneff; `core_tag=None` ("off") gives 17.93852 us and None for the core values. Fix: add these two cases to
   `tests/test_switching.py`.
4. minor: suite/src/photonsuite/switching.py:16 (module docstring). "E x H* is the power density": the
   time-averaged power density is 1/2 Re(E x H*). The formula is correct (the factor 2 of d(n^2) = 2 n dn cancels
   the 1/2), but the sentence is loose. Fix: "1/2 Re(E x H*) is the time-averaged power density".
5. minor: suite/src/photonsuite/switching.py:158 (one tuple monitor per thermal cell). thermal_gpu
   `_monitor_index` makes a full-grid boolean mask for each tuple monitor, so the host work is

6. minor: suite/src/photonsuite/switching.py:226-233 and :145. `slab_rise` with height 0 returns nan (0/0); only
