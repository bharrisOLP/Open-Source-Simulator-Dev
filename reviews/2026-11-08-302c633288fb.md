1. minor - fdtd_gpu/README.md:353-357 (the n = 1.5 explanation). The text says that the field error grows "about
   as k (k dx)^2 L (1 - S^2), that is about as n^3", because the Courant number S = c dt / (n dx) is lower in the
   medium. Reviewer run F (2-D Ez, res 20, the square of 1.0 um, 72 points at 1000 um) shows that the field
   error is a function of k = n omega only. The medium and S have no effect on it:
   - n = 1.5, f = 0.4 to 0.6 (n f = 0.6 to 0.9): 9.3e-4, 4.98e-3, 9.83e-3, 1.21e-2, 1.09e-2 (equal to the logged
     row).
   - n = 1, f = 0.6 to 0.9 (fcen 0.75, df 0.3; the same k): 1.10e-3, 4.91e-3, 1.03e-2, 1.28e-2, 1.21e-2.
   - A PML of 2 um instead of 1 um changes the errors by less than 1e-6.
   Also, the error does not grow as k^3: it grows 12 to 13 times from n f = 0.6 to 0.825 (k^3 gives 2.6 times). The
   factor 9.0 is the ratio of two points at different k (2 pi 0.6 and 2 pi 0.9) on a steep curve. The logged rows
   agree: 3-D n = 1.5 at f = 0.4 (n f = 0.6) gives 1.54e-3, and n = 1 at f = 0.6 gives 1.69e-3. Only the global
   phase rest depends on the medium (n f = 0.9: 1.46e-2 rad in n = 1.5, 1.10e-2 rad in vacuum). The phase rest
   is removed before the field error is calculated. The conclusion of the text is correct (the FDTD
   discretization, second order, not the transform). Fix: say that the error is a function of k dx = n omega dx
   (a vacuum run at the same k gives the same field errors). Say that it grows steeply with k dx in this band. Say
   that the factor (1 - S^2) changes only the global phase. Remove "about as n^3".
